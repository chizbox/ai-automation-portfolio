# Project: Rolan Daniel Portfolio Website

## Purpose
A single-page freelance portfolio that wins clients for Rolan Daniel, an AI automation specialist. The n8n automation projects are the focus of the page. Everything else is brief and supporting.

## Stack and file rules
- Plain HTML, CSS, and JavaScript only. No frameworks, no build step.
- Keep everything in three files: index.html, styles.css, script.js.
- Images live in the images/ folder. The profile photo is profile.png (transparent cutout) in the project root.
- Workflow screenshots are images/<project-name>.png.

## Design rules
- Professional, polished, and straightforward, like a senior consultant's portfolio.
- Light background, generous white space, one muted accent color.
- Refined serif and sans-serif pairing. Do not use Inter or Roboto.
- Subtle hover and scroll effects only. No gimmicks, no heavy animation, no stock template look.
- Fully mobile-responsive. Test at phone, tablet, and desktop widths.

## Content rules
- Page order: Hero, Projects, Services, How I Work, Experience, About, Contact.
- Never invent facts, numbers, clients, or testimonials. Use clearly marked placeholders for anything missing (email, booking link, other links).
- Prices are in Philippine pesos where shown. Location: Sta. Rosa, Laguna, Philippines.
- Keep the Disney SRE callout compact. The n8n projects stay the focus.

## Quality checklist (before saying a task is done)
- Semantic HTML, alt text on every image, keyboard-accessible links and buttons.
- SEO meta tags and Open Graph tags present.
- Page loads fast: optimized images, no unused code.
- No console errors. All links and buttons work.

## Working style
- Use plan mode for big changes and show the plan first.
- Make small, focused changes. Do not rewrite unrelated sections.
- Run a local preview with `npx serve .` to check changes.
- Suggest a git commit message after each good change.
