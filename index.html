Accounts Payable Invoice Processing

Built with n8n

Turns invoice emails into clean spreadsheet rows, with no manual data entry.

Problem

Invoices arrive as PDF email attachments and someone has to type each one into a tracker. It is slow, and duplicates and typos are easy to miss.

Tools

  • n8n
  • Gmail
  • Google Sheets
  • OpenRouter (Gemini 2.5 Flash Lite)

Highlights

  • Duplicate protection by invoice number
  • Strict don't-guess extraction
  • Failure path with labeling and error logging
  • Handles several attachments per email

Result

Invoice details land in the tracker automatically, duplicates are blocked, and failed emails are labeled and logged for review.

Typically cuts manual entry from about 3 to 5 minutes per invoice to about 30 seconds of review.

HR Evaluation and Job Posting Assistant with AI

Built with n8n

From application form to scheduled phone interview, with AI doing the screening.

Problem

Recruiters spend hours reading CVs, comparing them with job descriptions, writing follow-ups, and arranging calls, and most applicants aren't a fit.

Tools

  • n8n
  • Airtable
  • Google Drive
  • Gmail
  • Google Calendar
  • OpenRouter

Highlights

  • Several AI agents with different jobs: scorer, question writer, email writer, scheduler
  • A dynamic form built from AI-generated questions
  • Calendar booking by an AI agent
  • Every stage tracked in Airtable

Typically screens a batch of 50 CVs in about 10 minutes instead of a few hours by hand.

Facebook Messenger AI Assistant for an Online Toy Store

Built with n8n

An AI assistant that answers customer messages with live stock and price information, 24/7.

Problem

A small online toy shop gets the same questions all day (availability, price, condition, shipping), and answering each by hand slows down sales.

Tools

  • n8n
  • Facebook Graph API
  • Groq
  • Google Sheets
  • Google Docs

Highlights

  • Answers come only from the store's own data
  • Asks which product when several match
  • Prices in Philippine pesos
  • Retries and a polite fallback so no customer is left without a reply

Result

Customers get instant answers from live inventory, and anything the bot can't answer goes to the owner instead of being guessed.

Typically replies within seconds, at any hour, instead of waiting for me to be online.
