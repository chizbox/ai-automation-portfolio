Invoice processing

~30 sec per invoice

Invoice emails become clean spreadsheet rows, with duplicates blocked before they are saved.

How it's built

Problem

Invoices arrive as PDF email attachments and someone has to type each one into a tracker. It is slow, and duplicates and typos are easy to miss.

Tools

  • n8n
  • Gmail
  • Google Sheets
  • OpenRouter (Gemini 2.5 Flash Lite)

Highlights

  • Duplicate protection by invoice number
  • Strict don't-guess extraction
  • Failure path with labeling and error logging
  • Handles several attachments per email
